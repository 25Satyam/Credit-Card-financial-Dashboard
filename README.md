# Credit-Card-financial-Dashboard
📊 An interactive dashboard to track and visualize credit card expenses, spending trends, and financial insights. Built with Power BI
## 💳 Credit Card Financial Dashboard

A responsive and interactive financial dashboard designed to help users 
track credit card transactions, monitor spending habits, and gain actionable 
insights through clean data visualizations.

### Features
- 📊 Visual breakdown of expenses by category
- 📅 Monthly & weekly spending trends
- 💰 Budget tracking and limit alerts
- 🔍 Transaction filtering and search
- 📈 Interactive charts and summary cards

Built with Power BI
